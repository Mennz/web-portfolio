# Página de portfólio

Página pessoal de uma vitrine simples: apresentação, grid com os últimos
projetos e uma seção de contato. HTML e CSS puro, sem nenhum framework.

## O que pratiquei

- `flexbox` no cabeçalho e na seção de apresentação
- `grid` para os cards de projeto, com `repeat()` e `1fr`
- media query pra empilhar tudo abaixo de 700px
- um avatar só com CSS (círculo + iniciais), sem precisar de foto de verdade

## Como rodar

Abrir o `index.html` direto no navegador, não precisa de servidor.

```
start index.html
```
